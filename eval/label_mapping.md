# Label mapping used by the evaluation

Generated by `eval/load_datasets.py`. Source labels are mapped to the tool's five types; every other label is dropped (not scored).

- Adjacent name parts (first + last name) are merged into one `NAME` span.
- Address components are merged into one `ADDRESS` span. City/state/postcode labels only count when they are attached (gap of `, ` or similar) to a street/building component. A bare city ("users from London") is not personal-address data for this tool, so it is dropped.
- `ORG_ADDRESS` predictions are scored as `ADDRESS`.
